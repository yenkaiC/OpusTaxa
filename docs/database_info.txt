This folder holds the reference databases used by the OpusTaxa metagenomics
pipeline. Nothing here is generated by us -- every database is downloaded
unmodified from its upstream provider by the pipeline's download rules, which
run automatically on first use.

Each section below records: what the database is, the tool and tool version
that uses it, the database version, where it came from, the command that
fetched it, and the date it was downloaded.

Point a pipeline run at this folder with:

    snakemake ... --config databaseDirectory=/path/to/this/folder

Do not rename or move the subfolders. The tools look for fixed paths inside
them.

Total size: ~168 GB.

nohuman/                                                               5.9 GB
================================================================================
What      : A Kraken2-format index of human genome sequence, used to identify
            and remove human reads from samples before any analysis. Built from
            the Human Pangenome Reference Consortium (HPRC) assemblies, so it
            covers more human genetic diversity than a single reference genome.
Used by   : NoHuman v0.5.0 (https://github.com/mbhall88/nohuman)
DB version: HPRC.r2  (released upstream 2025-11-19)
Source    : https://ndownloader.figshare.com/files/59658306
            Release list: https://github.com/mbhall88/nohuman/blob/main/config.toml
MD5       : bda8fb2ffb1a0b4cbeb880cbc4d79fc6
Command   : nohuman --download --db <dir>
Downloaded: [fill: YYYY-MM-DD]
Layout    : nohuman/HPRC.r2/db/{hash,opts,taxo}.k2d

metaphlan/                                                              34 GB
================================================================================
What      : The ChocoPhlAn marker-gene database: ~5.1 million clade-specific
            marker genes covering bacteria, archaea, eukaryotes and viruses.
            MetaPhlAn maps reads to these markers to estimate the relative
            abundance of each species-level genome bin (SGB).
Used by   : MetaPhlAn v4.2.4 (https://github.com/biobakery/MetaPhlAn)
DB version: mpa_vJan25_CHOCOPhlAnSGB_202503  (January 2025 release)
Source    : http://cmprod1.cibio.unitn.it/biobakery4/metaphlan_databases
            Docs: https://github.com/biobakery/MetaPhlAn/wiki/MetaPhlAn-4.2
Command   : metaphlan --install --index mpa_vJan25_CHOCOPhlAnSGB_202503 \
                --db_dir <dir>
Downloaded: [fill: YYYY-MM-DD]
Note      : The index name is set in OpusTaxa's config.yaml (metaphlan_index).
            StrainPhlAn, if enabled, uses this same folder.

singlem/                                                               9.7 GB
================================================================================
What      : A "metapackage" of HMMs and reference sequence databases for ~60
            universal single-copy marker genes, with GTDB taxonomy attached.
            SingleM uses it to profile communities and to estimate what
            fraction of a sample is represented by known genomes.
Used by   : SingleM v0.21.4 (https://github.com/wwood/singlem)
DB version: S6.5.0.GTDB_r232.metapackage_20260319
            (SingleM metapackage 6.5.0, built on GTDB release 232)
Source    : Zenodo -- https://zenodo.org/records/20150069
Command   : singlem data --output-directory <dir>
Downloaded: [fill: YYYY-MM-DD]

kraken2/                                                                16 GB
================================================================================
What      : The PlusPF k-mer index, capped at 16 GB. Contents: RefSeq archaea,
            bacteria, viral, plasmid, human, UniVec_Core, plus protozoa and
            fungi. Kraken2 assigns reads to taxa by exact k-mer matching;
            Bracken then re-estimates abundances at a chosen rank using the
            .kmer_distrib files in the same folder.
Used by   : Kraken2 v2.1.6 (https://github.com/DerrickWood/kraken2)
            Bracken (bundled in the same environment)
DB version: k2_pluspf_16gb, index build dated 2025-10-15
Source    : https://genome-idx.s3.amazonaws.com/kraken/k2_pluspf_16_GB_20251015.tar.gz
            Index list: https://benlangmead.github.io/aws-indexes/k2
Command   : wget <url above> ; tar -xzf ...
Downloaded: [fill: YYYY-MM-DD]
Note      : To use a different Kraken2 index, replace the URL in
            Workflow/rules/kraken2.smk and re-download into an empty folder.

            https://card.mcmaster.ca/latest/variants  (WildCARD variants)

Downloaded: [fill: YYYY-MM-DD]

            Taxonomy     GTDB_r232 and UHGV_default metadata
Source    : http://faust.compbio.cs.cmu.edu/sylph-stuff/gtdb-r232-c200-dbv1.syldb

            Database list: https://sylph-docs.github.io/pre%E2%80%90built-databases/

Downloaded: [fill: YYYY-MM-DD]

NOTES
================================================================================

1. Reproducibility. Most databases above are versioned and can be re-fetched
   exactly. Two cannot: CARD (unversioned "latest" URL) and the antiSMASH
   bundle (tied to the antiSMASH release). For those, the copy in this folder
   is the record -- do not delete it while analyses are still being written up.

2. Sharing. This folder is read-only to other users of the project. Point your
   own OpusTaxa runs at it with --config databaseDirectory=<this path> rather
   than downloading your own copy. OpusTaxa only downloads a database when it
   is missing, and treats existing databases as "ancient" so a shared copy
   never triggers re-analysis of your samples.

3. Every database above is distributed by a third party under its own licence
   and citation requirements. Cite the database as well as the tool in any
   publication.
